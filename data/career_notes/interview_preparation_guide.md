# Technical Interview Preparation Guide

## 1. Technical Coding & Data Structure Preparation
- **Core Topics**: Arrays, Strings, Hash Maps, Linked Lists, Trees, Graphs, Binary Search, Dynamic Programming.
- **Problem Solving Strategy**:
  1. Clarify edge cases and constraints before writing code.
  2. Explain your approach out loud to the interviewer (time and space complexity tradeoffs).
  3. Write clean, modular code with descriptive variable names.
  4. Test your code against sample inputs and boundary conditions.

## 2. System Design & Behavioral Interview Strategies
- **System Design Framework**:
  - Define functional requirements and non-functional goals (scalability, latency, availability).
  - Estimate scale (QPS, storage, bandwidth).
  - Draw high-level architecture: Clients, API Gateways, Load Balancers, Backend Services, Caching Layers (Redis), and Databases.
- **Behavioral Questions (STAR Method)**:
  - **Situation**: Context of the project or challenge.
  - **Task**: Your specific responsibility.
  - **Action**: Detailed steps you took to address the challenge.
  - **Result**: Measurable outcomes and lessons learned (e.g., "Increased system uptime to 99.9%").
